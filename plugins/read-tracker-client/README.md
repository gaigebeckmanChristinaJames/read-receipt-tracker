# 已读追踪（HChat 客户端）

轻量级微信消息已读追踪的 HChat 客户端插件。配合「已读服务器」服务端插件使用，通过在消息中嵌入 1x1 透明像素统计已读人数。

作者：做梦

## 配套服务端

- 仓库：https://github.com/gaigebeckmanChristinaJames/read-receipt-tracker
- 服务端以 HChat / WeKit 插件形式运行，内置 HTTP 服务和 cloudflared 公网隧道

## 安装

1. 先在 HChat 中安装并启用「已读服务器」服务端插件，等待隧道连接成功
2. 将整个 `已读追踪` 文件夹复制到 `Hchat/脚本插件/`
3. 在 Hchat 中启用本插件，点击插件右侧的设置按钮
4. 填写服务器地址（服务端插件的隧道地址，例如 `https://xxx.trycloudflare.com`），保存

## 使用

- 默认以 `#` 开头发送追踪消息，例如 `#你好`。插件会发送一条引用 AppMsg 追踪卡片，封面为远程像素图片
- 输入 `/已读` 或 `/rr`，查询最近发送的一条追踪消息的已读人数
- 输入 `/已读面板` 或 `/rr-panel`，在浏览器打开服务端管理面板
- 触发前缀可在插件设置中修改。前缀留空时，所有通过发送按钮发送的非命令文本都会启用追踪
- 已发送的追踪消息会在气泡时间旁实时显示「已读 N 人」

## 说明

- 已读人数按请求来源 IP 去重，不等同于微信账号人数。同一网络下的多个设备可能只计为一人，切换网络或 VPN 也可能重复计数
- 只有接收方客户端加载了消息中的远程封面，服务器才会记录读取。微信版本、网络策略、缓存或禁止加载远程资源都可能影响结果
- 追踪消息依赖微信对引用消息中视频号封面的渲染行为。微信版本或风控策略变化时可能显示成灰色媒体占位卡片
- 会优先通过 DexKit 定位微信内部 XML 解析与六参数 AppMsg 发送链路；定位失败时回退 Hchat `sendXmlMsg`
- 该功能会让接收方设备请求你配置的服务器并记录其 IP。部署和使用时应遵守适用的隐私与数据保护要求
