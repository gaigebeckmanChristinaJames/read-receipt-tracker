轻量级微信消息已读回执服务器 · WeKit / WuYu 专用后端
像素埋点 已读追踪核心
1×1 透明 GIF 无感记录消息已读
功能：注册消息后获得一个像素链接，将链接嵌入微信消息/网页后，对方打开即自动记录已读。

工作原理：
  • 服务器返回 1×1 透明 GIF（47 字节，零感知）
  • 自动记录读取者 IP、User-Agent、时间戳
  • 同一消息 + 同一 IP 只计一次（智能去重）
  • 支持 X-Forwarded-For / X-Real-IP 反向代理
接入示例： GET /pixel?wxId=xxx&id=消息ID
IP 定位 中文省市 · 可选开关
自动获取读取者国家/省份/城市
功能：每次已读自动查询 IP 归属地，返回中文省市信息（如：中国 上海市 上海）。

三级接口自动备份（无需 Key）：
  • ip-api.com（中文）→ ipwho.is（中文）→ ipinfo.io（英文兜底）
  • 支持 IPv4 与 IPv6，超时 5 秒静默降级
  • 记录字段：国家 / 省份 / 城市
关闭定位（Lite 模式）： ENABLE_GEO=0 python app.py —— 零外部请求、响应最快
管理后台 Web 控制台
深色主题 · 消息列表 · 统计 · CSV 导出
功能：内置 Web 管理面板，浏览器直接访问。

  • 📊 总消息数 / 总已读 / 平均已读 / 已定位统计
  • 🔍 搜索：按内容 / wxId / ID 三字段过滤
  • 📍 首页列表显示每条消息定位到的城市数
  • 📥 一键导出 CSV（中文支持）
  • 📦 批量查询已读状态（弹窗输入 ID 列表）
  • 🗑 单条删除 / 一键清空
访问： http://127.0.0.1:5000（可选 API Key 保护）
客户端 API WeKit / WuYu 对接
JSON 接口，直接返回省市定位
功能：为微信模块客户端提供全套 JSON 接口。

  • POST /register — 注册消息，返回 pixel_url
  • GET /count?wxId=&id= — 已读数 + 每条定位（省市）
  • GET /api/reads/<id> — 完整已读记录 JSON
  • GET /api/messages — 消息列表 JSON
  • GET /message/<id>?json=1 — 详情 JSON
  • GET /batch-status?ids= — 批量查询
定位返回示例： {"location":"中国 上海市 上海","province":"上海市","city":"上海"}
一键部署 Termux / Linux / Docker
零下载全内嵌 · 一条命令跑起来
功能：全代码内嵌脚本，不下载仓库文件、不写 /tmp、自动配清华源。

Termux（推荐）：
bash <(curl -fL "https://cdn.jsdelivr.net/gh/gaigebeckmanChristinaJames/read-receipt-tracker@main/scripts/ultimate-setup.sh")

Linux 服务器：
git clone ... && cd read-receipt-tracker && pip install flask && python run.py

Docker：
docker compose up -d

内网穿透（可选）：
cloudflared tunnel --url http://127.0.0.1:5000
安全与性能 防刷防堵
限流 + 认证 + WAL 并发优化
功能：生产级防护，微信模块高频调用也不怕。

  • ⚡ SQLite WAL 模式：写不阻塞读，并发响应快
  • ⏱ busy_timeout 5 秒：并发写自动等待不报错
  • 🛡 pixel 非阻塞：写库失败不影响 GIF 返回
  • 🔐 API Key 认证：管理接口可加密保护
  • 🚦 IP 级限流：默认 60 次/分钟，可配置
  • 🧹 Termux 自动清理过期记录（--cleanup N 天）
认证配置： API_KEY=你的密钥 python app.py
双后端实现 Python + C++
Flask 全功能版 + C++ 高性能版
功能：两套后端任选。

  • Python 版（推荐）：Flask + uv/ruff 工具链，功能最全（定位/后台/客户端 API）
  • C++ 版：meson + ninja 构建，原生 HTTP 服务器，零依赖高性能
编译 C++ 版：
cd cpp && meson setup builddir && meson compile -C builddir && ./builddir/rrtracker-server
