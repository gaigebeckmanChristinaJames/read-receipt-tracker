📬 read-receipt-tracker 安装教程

轻量级消息已读追踪服务 · WeKit / WuYu 微信模块专用后端 · 支持 Termux / Linux / Docker

1 首次使用：安装 curl

全新 Termux 环境没有 curl，先执行这一步（已装过的可跳过）。

pkg update -y && pkg install curl -y

2 一键部署 标准版 · 含 IP 定位

自动配置清华源 → 安装 Python + Flask → 内嵌代码落地 → 前台运行。支持 IPv4/IPv6 定位（三接口备份）。

bash <(curl -fL "https://cdn.jsdelivr.net/gh/gaigebeckmanChristinaJames/read-receipt-tracker@main/scripts/ultimate-setup.sh")

2b 一键部署 Lite 版 · 无定位

去除 IP 定位功能，响应更快、零外部依赖。

bash <(curl -fL "https://cdn.jsdelivr.net/gh/gaigebeckmanChristinaJames/read-receipt-tracker@main/scripts/ultimate-setup-lite.sh")

3 配置 Cloudflare Tunnel（可选）

需要公网地址时，另开一个 Termux 会话执行以下两条命令。

pkg install cloudflared
cloudflared tunnel --url http://127.0.0.1:5000

隧道日志中会出现 https://xxx.trycloudflare.com 公网地址。

4 管理后台地址

部署完成后，管理后台：

http://127.0.0.1:5000
